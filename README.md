# EPHEMERIS OMI-CAM

**EPHEMERIS OMI-CAM** est une application Android d'éphémérides des annivesaires développée spécifiquement pour la **Province des Missionnaires Oblats de Marie Immaculée du Cameroun**. Elle permet d'alerter chaque jour sur les anniversaires à célébrer.

---

## 🚀 Fonctionnalités
- 📅 Alertes quotidiennes pour les anniversaires à célébrer.
- 🔭Alertes avec possibilité de notifications.
- 📱 Interface fluide et optimisée pour une consultation immédiate.

## 🛠️ Configuration & Installation
L'application compile sous Android Studio.
- **Version cible (Target SDK) :** API 37 (Android 7+)
- **Déploiement :** Assurez-vous que l'attribut `android:exported="true"` est configuré dans le manifeste pour l'activité principale.
